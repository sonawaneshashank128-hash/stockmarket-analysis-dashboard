This dashboard displays historical daily closing prices. It does not provide streaming, intraday, or execution-grade quotes.

  2. Install the data-fetcher dependencies if needed.
  3. Run the command below, then reload this dashboard.
py -m pip install -r requirements.txt; py data\fetch_real_data.py
